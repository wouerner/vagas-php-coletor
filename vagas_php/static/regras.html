Por transparência, estas são as regras que decidem o que aparece no site. Esta página é gerada a partir do próprio código do filtro: o que está aqui é exatamente o que o coletor aplica.

Regras gerais
  • Só aparecem vagas publicadas nas últimas 72 horas.
  • A mesma vaga anunciada várias vezes (mesmo título e empresa, na mesma fonte) aparece uma vez só.
  • Issues fechadas no GitHub saem do site.
  • As regras de cada grupo são aplicadas na ordem abaixo: a primeira que se encaixa decide.
  • Quando uma regra muda, ela é reaplicada às publicações que já estão na base.
  • O que escapa das regras pode ser descartado à mão, e fica listado no fim da página.
